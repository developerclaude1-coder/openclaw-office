# synaptic-tagging
MECHANISM: Synaptic tagging and capture: a weak event sets a cheap, decaying, synapse-local eligibility tag; a strong/salient event triggers an unaddressed cell-wide broadcast of plasticity proteins; persistence = AND(tag alive, broadcast fired) within overlapping windows, order-independent — so a later salient event retroactively consolidates recently tagged weak events (Frey & Morris 1997 PMID:9020359; Frey & Morris 1998 PMID:9704995; Redondo & Morris 2011 PMID:21170072).
ETTZ EQUIVALENT: NONE. The two candidates fail on inspection. Flow refs (ORGANON O-8) are permanent minted identity threads — axonal pathway tracing: no decay window, no durability upgrade, no salience conjunction; a flow ref makes a journey READABLE as one thread but never changes what gets consolidated. Claims' trials (+confirm/−fail/~anomalous) are slow evidence accumulation on an ALREADY-PROMOTED semantic object — proto-Hebbian counting, not eligibility tagging: a trial updates the claim it tests and touches nothing nearby in time. The closest structural relatives elsewhere — the trigger fabric's confirming envelope (two-phase commit, but confirming the SAME action, never a neighbor), memory-nightly (circadian, exhaustive, salience-blind — maps to sleep replay, not capture), entropy dwell clocks (30-day, time-based, about disposal not promotion), and the bank's usage balances (use-counting, not windowed rescue) — none performs retroactive, time-windowed, salience-gated promotion.
VERDICT: missing

## Argument for
Superficially the analogy to flow refs is tempting: both are small markers attached at the item that let later processing treat related events as one thing, and the trigger fabric's act-then-confirming-envelope loop has exactly the Redondo & Morris 2011 (PMID:21170072) two-phase shape — induction creates only the POTENTIAL for change, a second signal commits it. Claims' trials likewise resemble capture in that an external event (a trial) changes a record's standing. And ETTZ's append-only, timestamped spine means the order-independence biology buys with a physical tag (weak-before-strong works as well as strong-before-weak — Frey & Morris 1998 PMID:9704995) is available for free by scanning backward over the log — the substrate for STC is unusually well-prepared in ETTZ.

## Argument against
The computational logic is a CONSOLIDATION WINDOW plus RETROACTIVE CREDIT ASSIGNMENT, and no ETTZ mechanism evaluates that conjunction. STC needs four elements: (1) an optimistic, cheap, DECAYING per-item eligibility marker (tag decays <3h; rescue robust at 5min–1h, gone by 2–4h — Frey & Morris 1998); (2) a separate high-threshold salience gate authorizing a broadcast (behaviorally: novelty, not familiarity — Moncada & Viola 2007 PMID:17626208; Ballarini 2009 PMID:19706547; Wang 2010 PMID:20962282; upstream, a prediction-error signal — Schultz 1997 PMID:9054347, Takeuchi 2016 PMID:27602521); (3) promotion computed as AND(tag alive, broadcast fired); (4) as a result, weak events gaining durability BECAUSE something important happened nearby in time. ETTZ has none of the four as mechanism: flow refs never decay and never promote; trials count evidence with no time window and no spillover to neighbors; memory-nightly folds everything on a clock regardless of salience (and STC argues nightly cadence is too coarse for a 1–2h window — the awake-replay result, Jadhav 2012 PMID:22555434, further shows biology consolidates opportunistically between episodes, not only in a batch window); entropy's 30-day dwell clock runs the opposite direction, toward disposal. This lands exactly on the owner's own suspected sharpest gap: nothing PROMOTES co-salient episodic patterns into claims/procedures automatically. The critic's hedges do not soften this: PKMzeta-as-maintenance is contested (Volk 2013 PMID:23283174) and the D1/D5 gate lacks a primary source in the sweep, but the tag-and-capture LOGIC — the part being mapped — rests on the uncontested Frey & Morris core.

## Strongest objection
"The verdict should be 'have it' (or at least 'partial'), because ETTZ's append-only spine with time-travel queries (--asof) already CONTAINS every weak event forever — nothing ever decays, so nothing ever needs rescuing. Retroactive credit assignment is trivially achievable at query time: any later salient event can scan backward over the log. Biology needs a physical tag only because early-LTP physically fades; ETTZ's 'early-LTP' never fades, so STC solves a problem ETTZ does not have — arguably a doctrinal difference (never erase), not a missing mechanism."

## Verdict survives because
The objection confuses retention with consolidation, and substrate with mechanism. What is at stake in STC is not whether the raw trace survives (in ETTZ every envelope is permanent by law) but whether a weak event is PROMOTED into the durable stores that shape behavior — claims and procedures. That promotion tier exists in ETTZ (4 claims, 12 procedures — all hand-seeded) while the episodic tier holds 71,225 envelopes, so the selection problem STC solves is fully present: which of 71k weak traces deserve semantic/procedural commitment? Nothing computes that. The capability to scan backward is inert: no trigger fires it, no window bounds it, no promotion path consumes its output. A mechanism is a thing that runs; ETTZ has the log but not the loop. Nor is it 'deliberately different': owner doctrine governs DISPOSAL (never erase) and says nothing against automatic promotion — the owner himself flags absent episodic-to-semantic promotion as the suspected sharpest gap, an acknowledged hole, not a ruling. So 'missing' stands, with the honest rider that the substrate makes the missing mechanism unusually cheap to add.

## Missing pieces
- A decaying per-event eligibility window (hours-scale, distinct from entropy's 30-day dwell clock) so late salience cannot promote arbitrarily stale events
- A salience event class acting as commit authorization separate from content volume — the D1/D5 lesson (gate logic solid; primary sourcing thin per critic) refined by prediction-error gating (Sevenster 2013 PMID:23413355): surprise opens the window, familiarity does not — candidate signals already exist (anomalous claim trials, error-stream envelopes, owner CHOICE envelopes, new ignorance-graph questions)
- The conjunction evaluator: a pass that fires ON salience, scans the bounded window backward and forward (order-independence per Frey & Morris 1998), and emits promotion candidates — a salience-triggered mini-fold complementing circadian memory-nightly (which maps to sleep replay, not capture; awake replay Jadhav 2012 argues for exactly this event-triggered mode)
- A promotion path that consumes captures: episodic pattern → draft claim or procedure candidate for owner review — the episodic-to-semantic abstraction step, absent everywhere in ETTZ
- Locality conditioning on capture (the branch-compartment result — Govindarajan 2011 PMID:21220104, per critic's correction of the 2006 model paper): co-promotion should require a shared flow ref or subject, not bare temporal proximity, or the 12 interleaved sources make the window capture noise
- Optional, doctrine-sensitive: inverse tagging (Okuno 2012 PMID:22579289) — marking non-captured co-windowed siblings for EARLIER entropy review (a demotion, not a deletion; biology removes receptors, not the synapse) — must remain owner-gated

## Adoptable proposal: Capture Pass: salience-triggered windowed promotion tagging
- biological principle: Synaptic tagging and capture — consolidation as the time-windowed, order-independent conjunction of a cheap local eligibility trace and a salience-gated broadcast, so weak events are retroactively promoted because something important happened nearby in time (Frey & Morris 1997/1998; Redondo & Morris 2011; behavioral tagging — Moncada & Viola 2007, Ballarini 2009, Wang 2010; prediction-error gating — Sevenster 2013).
- ettz change: Smallest real change: (1) define a sparse, enumerated SALIENCE event class in the n8n trigger fabric — error-stream envelopes, ~anomalous claim trials, owner CHOICE envelopes, new ignorance-graph questions; (2) when one fires, run a bounded scan (±2h on event timestamps, not ingest time) over spine events/, keeping only envelopes sharing a flow ref or subject with the salient event; (3) append a new 'capture' envelope kind (schema extension in memory-spine/schema) linking the salient event to each captured weak envelope, with why; (4) memory-nightly's next fold reads capture envelopes and renders promotion CANDIDATES (draft claims/procedures) on the memory face and ignorance graph for owner review. Purely additive; no disposal path touched; auto-minting of claims explicitly excluded from v1.
- cost: Build: one envelope kind, one n8n trigger rule, one windowed indexed scan query, one fold change to render candidates — days of work on existing substrates. Runtime: one bounded scan per salience event (cheap, but must be rate-limited); the fold addition must ride the existing exact-fingerprint cache or it worsens the known 60s+ cold-fold scaling pain.
- risks: (1) Salience inflation: if the event class is loose, every window is 'novel' and the pass promotes everything — biology's gate fires on prediction error, not activity (familiar environments fail to rescue, Ballarini 2009); the class must be sparse, and an anomaly storm (e.g. a flapping heartbeat emitting hundreds of error envelopes) must be normalized/rate-limited or it fires hundreds of overlapping scans and mints thousands of junk captures. (2) False association by co-windowing: 12 interleaved sources across two machines make temporal proximity weak evidence of relatedness; without the shared-flow-ref/subject condition (ETTZ's analog of same-neuron/same-branch locality), a NAS SMART anomaly co-promotes an unrelated music-review envelope and the claims layer accretes spurious candidates. (3) If captures ever auto-mint claims, wrong predicates become permanent by doctrine (claims never delete, windows only close) — hence candidates-only in v1. (4) Where the biology would be WRONG for ETTZ: the <3h tag decay is tuned to protein lifetimes, not estate rhythms — the pull-only Collector can deliver a remote organ's envelopes hours late, so windows must run on event timestamps or legitimate captures are missed; and importing inverse tagging literally (weakening all non-participants on every commit) would push routine healthy traffic toward entropy review every time an anomaly lands nearby — the negative half stays out of v1 entirely.
- owning session: memory-nightly (owns consolidation semantics; the capture pass is its event-triggered sibling), with the WHEN carried by the n8n trigger fabric and capture envelopes homed in the memory-spine like all events. No new session required.
- priority argument: Ranks at or near the top of all proposals: it is the direct answer to the owner's self-identified sharpest gap (no automatic episodic→claims/procedures promotion), it imports the one piece of STC logic no existing organ carries while reusing every substrate ETTZ already has (append-only log gives order-independence free; flow refs give locality; CHOICE/error/anomaly envelopes give candidate salience signals; the fold gives the rendering path), and its v1 is doctrine-clean — purely additive, owner-reviewed, touching no disposal path. Against it: it depends on getting the salience class right, and a simpler repetition-counting promoter competes — but repetition-counting is the Hebbian/bank story, already partially present, whereas windowed retroactive rescue of one-off weak events is what nothing else covers.

## Doctrine notes
Three explicit touchpoints with owner law. (1) Compress-and-archive-never-erase: the capture pass is append-only by construction and violates nothing; but STC's complement, inverse tagging (Okuno 2012 — non-participants are actively WEAKENED during each commit), presses directly on disposal doctrine. Biology's version is itself demotion, not destruction (AMPA-receptor removal; the synapse survives), so a mapped form — marking non-captured co-windowed siblings for earlier kallimachos/entropy review, still passing grace verification, the custodian A-002 snapshot interlock, and owner authorization — is doctrine-compatible in principle, but it changes what enters the disposal pipeline and must be put to the owner as a separate ruling, not smuggled into the capture pass. (2) Nothing-builds-until-he-rules: v1 deliberately terminates at promotion CANDIDATES; auto-minting claims would let a mechanical process author permanent records (claims never delete, windows only close), shifting authorship of the estate's beliefs away from the owner — that step needs its own ruling. (3) Repairs-are-splices: an accepted capture becomes a decision envelope in the existing question→decision splice grammar (O-8), so the pass extends existing law rather than adding a new write mode.
