# engrams: Engrams: memory as distributed ensembles — activity-dependent tagging, allocation by intrinsic excitability, reactivation-as-recall, silencing vs erasure, and memory linking across time

## Summary
Semon's "engram" is now an operational object with three testable criteria: a sparse set of neurons activated by an experience, undergoing persistent physical change, whose reactivation is sufficient to reproduce recall behavior (Josselyn & Tonegawa 2020).

WRITE PATH (tagging). The tag is transcriptional, not synaptic. Encoding drives Ca2+ entry -> CaMK/MAPK -> phospho-CREB(Ser133) -> immediate-early genes (c-fos, Arc, Npas4). Experimentally the c-fos promoter drives tTA (TetTag) or CreER (TRAP); a permissive window is opened by withdrawing doxycycline (or dosing 4-OHT), so any neuron whose IEG transcription crosses threshold inside that window permanently recombines a payload (ChR2, hM3Dq, diphtheria-toxin receptor). Two engineering facts matter: the tag is a threshold-crossing detector on recent activity, carrying no content; and it is a latch — once recombined it never decays, so the tagged set outlives the memory's accessibility. Timescales: IEG transcription in minutes, protein in tens of minutes, tagging window ~24-48 h. Sparsity is severe: ~2-5% of dentate granule cells, ~10-20% of CA1/lateral amygdala. Reijmers 2007 established the quantitative correlate — the count of tagged-and-reactivated basolateral amygdala neurons scales with behavioral fear.

SUFFICIENCY. Liu 2012 optogenetically reactivated a ChR2-tagged dentate ensemble in a neutral context and produced freezing, context-specifically, with no natural cue present. Recall is ensemble reactivation. Ramirez 2013 pushed further: pairing artificial reactivation with shock installs a false memory for a context where nothing happened.

ALLOCATION. Membership is a competition, not a lottery. Han 2007: CREB overexpression in ~10-20% of lateral amygdala neurons biases those cells into the trace. Zhou 2009 and Yiu 2014 identify the mediating variable as intrinsic excitability (CREB lowers spike threshold and afterhyperpolarization); the rule is RELATIVE excitability in the moments immediately before training, and it can be imposed by any means (Kir2.1 dominant-negative, hM3Dq) — which both reroutes the memory and strengthens it. Winner-take-most, with lateral inhibition enforcing sparsity. Critically, the excitability bias is a leaky trace with an hours-long time constant: two events within ~6 h co-allocate to overlapping ensembles and become linked (fear transfers between contexts, one memory strengthens the other), while events ≥24 h apart actively disallocate to non-overlapping ensembles (Cai 2016; Rashid 2016). Temporal proximity is implemented as a decaying eligibility variable, not an explicit timestamp index.

STORAGE vs ACCESS. Ryan 2015 dissociates what software would conflate. Under protein-synthesis-inhibitor retrograde amnesia, engram cells lose their increased spine density and synaptic strength and the animal is amnesic to natural cues — yet direct optogenetic reactivation still retrieves the memory, and engram-to-engram connectivity is preserved. Identity lives in the CONNECTIVITY PATTERN; synaptic weights govern only whether a natural cue can pattern-complete into it. A "silent engram" is stored-but-unaddressable. The same dissociation recurs in early Alzheimer models, infantile amnesia, and ordinary forgetting; Ryan & Frankland 2022 generalize it — forgetting is a reversible accessible→inaccessible state transition, modulated by environmental mismatch, not deletion.

ERASURE. The only demonstrated true erasure is substrate destruction: inducible diphtheria-toxin ablation of the CREB-high allocated neurons permanently abolishes that specific memory, while ablating an equal random subset does not (Han 2009). Destroying the units is the sole route; everything short of it changes accessibility.

ADDRESSING. Two memories can share an ensemble and stay distinct because they occupy different input synapses onto the same cells; optogenetically potentiating or depotentiating one input pathway moves only one memory (Abdou 2018). The address is (cell set × input pathway), not the cell.

WHERE. Not a place. Roy 2022 surveyed 247 regions and found ~117 holding contextual-fear engrams; simultaneous reactivation of several yields stronger recall than any single one — a "unified engram complex." Kitamura 2017 adds the time axis: a prefrontal engram is generated at encoding but born SILENT, matures over ~2 weeks under hippocampal drive, while the hippocampal engram falls silent. Systems consolidation is a change in which copy is addressable, not a copy operation.

## Key mechanisms (computational logic)
- **IEG activity tagging as a gated threshold latch**: SIGNAL: recent depolarization integrated as Ca2+ -> phospho-CREB(Ser133). TAG: transcription of c-fos/Arc/Npas4 above a threshold, which in engineered systems drives tTA/CreER and a permanent recombination event. THRESHOLD: only cells in the top few percent of recent drive transcribe enough to latch. WINDOW: the tag is only writable while a gate is open (doxycycline withdrawn, 4-OHT present) — typically 24-48 h; outside it, activity leaves no durable mark. TIMESCALE: mRNA minutes, protein tens of minutes, latch permanent. Logic: the tag records THAT a unit participated, never WHAT it encoded, and once written it never expires — so the tagged set persists past the memory's usability.
- **Sparse winner-take-most allocation by relative intrinsic excitability**: SIGNAL: each candidate unit's excitability state (CREB-dependent reduction of afterhyperpolarization / spike threshold) in the seconds-to-minutes before encoding. RULE: rank, don't score — a unit joins the ensemble if its excitability is high RELATIVE to neighbors, so artificially raising it in any random subset captures the memory into that subset. THRESHOLD: enforced by lateral inhibition, yielding fixed sparsity (~2-5% dentate, ~10-20% amygdala/CA1) independent of how much is happening. RESULT: capacity is protected by refusing to write most events into most units; the substrate never writes everything.
- **Hours-scale excitability eligibility trace producing temporal memory linking**: SIGNAL: encoding transiently elevates the excitability of the units it recruited. DECAY: the elevation leaks away over hours. CONSEQUENCE: a second event arriving within ~6 h is co-allocated to overlapping units (memories become linked — fear generalizes across contexts, the first memory strengthens the second); an event ≥24 h later is actively DISALLOCATED to a disjoint set. Logic: temporal proximity is computed implicitly by a decaying analog variable, not by comparing timestamps, and disallocation is an active separation operation, not merely the absence of linking.
- **Reactivation-as-retrieval via pattern completion**: READ: a partial cue drives a subset of the ensemble; recurrent connectivity completes the rest past threshold and the behavior follows. SUFFICIENCY: bypassing cues entirely and forcing the ensemble optogenetically reproduces the memory, and forcing it during a new experience writes a false memory. Logic: there is no separate 'read the record' step — the pattern IS the content, and any process that reconstitutes the pattern constitutes recall, including artificial and erroneous ones.
- **Connectivity-vs-weights split: the silent engram**: TWO STATES, separately measurable. (a) STRUCTURE: which units are in the ensemble and how they are wired to each other — survives protein-synthesis blockade, amyloid pathology, infantile amnesia, and ordinary forgetting. (b) WEIGHTS: spine density and synaptic strength at engram-to-engram synapses — these are what a natural cue needs to pattern-complete, and they are what amnesia removes. DIAGNOSTIC: if direct activation retrieves but cues do not, the memory is stored and unaddressable, not lost. REPAIR: restoring the weights (optogenetic LTP at engram inputs) restores cue-driven access.
- **Silencing as the default disposal path; erasure requires destroying the units**: DEFAULT: forgetting flips an ensemble from accessible to inaccessible and is reversible, environmentally modulated, and treated as adaptive plasticity rather than as data loss. ERASURE: the only demonstrated permanent deletion is ablating the allocated units themselves (inducible diphtheria toxin in CREB-high neurons); killing an equal random subset does nothing. Logic: the system has no 'delete a memory' primitive — it has an accessibility switch, and true removal is an unrecoverable, substrate-level operation that must be aimed precisely at the allocated set.
- **Synapse-specific addressing within a shared ensemble**: PROBLEM: overlapping memories share cells, so cell identity cannot be the address. SOLUTION: each memory occupies a distinct input pathway onto those shared cells. TEST: optogenetically potentiating or depotentiating one input pathway alters exactly one memory and leaves the other intact, even to the point of complete amnesia for one while the linked one persists. Logic: the key is the pair (unit set × input channel); sharing units buys linkage without collapsing identity.
- **Systems consolidation as maturation of a copy born silent, plus multi-region distribution**: AT ENCODING: engrams are written simultaneously in hippocampus, amygdala, and prefrontal cortex — but the prefrontal one is generated SILENT (present, tagged, not cue-addressable). OVER ~2 WEEKS: the prefrontal engram matures under hippocampal drive while the hippocampal engram goes silent; the amygdala (valence) copy persists throughout. SCOPE: ~117 of 247 surveyed regions hold a piece of a single contextual memory, and co-reactivating several regions recalls more strongly than any one. Logic: consolidation is not copying — every copy is written up front, and what changes over time is which copy answers to natural cues.

## Citations
- Josselyn SA, Tonegawa S (2020). Memory engrams: Recalling the past and imagining the future. *Science*. PMID:31896692. [verified] — supports: Defines the engram operationally (Semon's original term; a sparse cell subset undergoing persistent chemical/physical change whose reactivation induces retrieval), and reviews the joint role of intrinsic excitability and synaptic plasticity plus the lifetime of an engram — the framing used throughout the summary.
- Reijmers LG, Perkins BL, Matsuo N, Mayford M (2007). Localization of a stable neural correlate of associative memory. *Science*. PMID:17761885. [verified] — supports: Introduces the c-fos-driven, doxycycline-gated transgenic tagging system (TetTag) that permanently marks neurons active in a defined window, and shows that basolateral amygdala neurons tagged during fear conditioning are reactivated at retrieval with the reactivated count correlating positively with behavioral memory strength.
- Liu X, Ramirez S, Pang PT, Puryear CB, Govindarajan A, Deisseroth K, Tonegawa S (2012). Optogenetic stimulation of a hippocampal engram activates fear memory recall. *Nature*. PMID:22441246. [verified] — supports: Demonstrates SUFFICIENCY: optogenetic reactivation of ChR2-labeled dentate gyrus neurons that were active during fear learning elicits freezing in a different, neutral context; effect absent in non-conditioned and EYFP controls and specific to the fear-associated tagged population.
- Han JH, Kushner SA, Yiu AP, Cole CJ, Matynia A, Brown RA, Neve RL, Guzowski JF, Silva AJ, Josselyn SA (2007). Neuronal competition and selection during memory formation. *Science*. PMID:17446403. [verified] — supports: Establishes allocation-by-competition: manipulating CREB function in subsets of lateral amygdala neurons changes the probability that an individual neuron is recruited into the fear memory trace, supporting a competitive selection model based on relative CREB activity at the time of learning.
- Yiu AP, Mercaldo V, Yan C, Richards B, Rashid AJ, Hsiang HL, Pressey J, Mahadevan V, Tran MM, Kushner SA, Woodin MA, Frankland PW, Josselyn SA (2014). Neurons are recruited to a memory trace based on relative neuronal excitability immediately before training. *Neuron*. PMID:25102562. [verified] — supports: Identifies intrinsic excitability (not CREB per se) as the allocation variable: several independent methods of raising excitability bias recruitment into the trace and enhance memory formation, and artificial activation of those neurons alone is a sufficient retrieval cue — the basis for the 'relative excitability immediately before encoding' rule.
- Han JH, Kushner SA, Yiu AP, Hsiang HL, Buch T, Waisman A, Bontempi B, Neve RL, Frankland PW, Josselyn SA (2009). Selective erasure of a fear memory. *Science*. PMID:19286560. [verified] — supports: Shows the only demonstrated route to true erasure: inducible diphtheria-toxin ablation of CREB-overexpressing (allocated) lateral amygdala neurons after learning permanently blocks expression of that fear memory, whereas ablating a comparable random subset does not.
- Ryan TJ, Roy DS, Pignatelli M, Arons A, Tonegawa S (2015). Engram cells retain memory under retrograde amnesia. *Science*. PMID:26023136. [verified] — supports: The storage-vs-access dissociation ('silent engram'): protein-synthesis-inhibitor amnesia removes the increased synaptic strength and spine density of engram cells, yet direct optogenetic activation still retrieves the memory and engram-cell-specific connectivity is retained — supporting connectivity pattern as the storage substrate and synaptic weights as the retrieval/accessibility mechanism.
- Cai DJ, Aharoni D, Shuman T, Shobe J, Biane J, Song W, Wei B, Veshkini M, La-Vu M, Lou J, Flores SE, Kim I, Sano Y, Zhou M, Baumgaertel K, Lavi A, Kamata M, Tuszynski M, Mayford M, Golshani P, Silva AJ (2016). A shared neural ensemble links distinct contextual memories encoded close in time. *Nature*. PMID:27251287. [verified] — supports: Establishes the hours-scale linking window: CA1 ensembles for two contexts overlap when acquired within a day but not a week apart; fear transfers between the linked contexts and the first memory strengthens the second only within a day; aged mice with lower excitability lose the overlap, and raising excitability restores linking.
- Rashid AJ, Yan C, Mercaldo V, Hsiang HL, Park S, Cole CJ, De Cristofaro A, Yu J, Ramakrishnan C, Lee SY, Deisseroth K, Frankland PW, Josselyn SA (2016). Competition between engrams influences fear memory formation and recall. *Science*. PMID:27463673. [verified] — supports: Shows the excitability-based competitive process is transient and bidirectional: it co-allocates overlapping neuronal populations to memories for events occurring close in time and DISALLOCATES non-overlapping populations for events at distal times — the basis for describing disallocation as an active separation operation.
- Abdou K, Shehata M, Choko K, Nishizono H, Matsuo M, Muramatsu SI, Inokuchi K (2018). Synapse-specific representation of the identity of overlapping memory engrams. *Science*. PMID:29903972. [verified] — supports: Demonstrates synapse-specific addressing: engram sharing underlies memory linkage, while synapse-specific plasticity preserves individual memory identity — optogenetic potentiation or depotentiation of the synapses specific to one memory affects only that memory, and complete amnesia for one memory leaves the linked memory in the shared ensemble intact.
- Kitamura T, Ogawa SK, Roy DS, Okuyama T, Morrissey MD, Smith LM, Redondo RL, Tonegawa S (2017). Engrams and circuits crucial for systems consolidation of a memory. *Science*. PMID:28386011. [verified] — supports: Shows prefrontal memory engram cells are generated rapidly during initial learning (via hippocampal-entorhinal and basolateral amygdala input) but become functionally mature only with time under hippocampal engram support, while hippocampal engram cells gradually become silent and amygdala engram cells persist — the 'born silent, matures later; consolidation changes which copy is addressable' claim.
- Roy DS, Park YG, Kim ME, Zhang Y, Ogawa SK, DiNapoli N, Gu X, Cho JH, Choi H, Kamentsky L, Martin J, Mosto O, Aida T, Chung K, Tonegawa S (2022). Brain-wide mapping reveals that engrams for a single memory are distributed across multiple brain regions. *Nature Communications*. PMID:35379803. [verified] — supports: Supports the 'unified engram complex': characterizing encoding-activated ensembles across 247 regions identified ~117 regions holding engrams for a single contextual fear memory, with brain-wide reactivation at recall, and simultaneous chemogenetic reactivation of multiple engram ensembles producing greater recall than reactivation of a single one.

## ETTZ relevance notes from researcher
WHERE-IS-A-MEMORY / fractal law, parent=union-of-children, GRAPHIFY, BINNA. Roy 2022's unified engram complex is the biological statement of ETTZ's fractal law: one memory is simultaneously written in ~117 regions, and co-reactivating several recalls better than any one. Design consequence: retrieval in ETTZ should co-activate the organ set rather than query a single store, and BINNA's merged-memory union is the right primitive — but recall quality should scale with how many organs light up, which is currently unmeasured. GRAPHIFY's ~150k-node graph is the right rendering surface for an ensemble; what is missing is an explicit ENSEMBLE ID naming the co-activated set.

FLOW REFS vs SYNAPTIC TAGGING (owner's question, answered). Flow refs are the closer analog than claims' trials — a flow ref is exactly an opaque id that travels with an item across organs so a journey reads as one thread, which is what an engram tag does (marks participation, carries no content, outlives the episode). But two properties are missing: (a) biology's tag is written only past a THRESHOLD and only inside an open WINDOW, whereas ETTZ writes an envelope for everything; (b) biology's tag is competitive and sparse. Claims' trials are the weight/accessibility layer, not the tag layer — the Ryan 2015 split (connectivity = identity, weights = addressability) maps cleanly: flow refs are the connectivity, claims' trials are the weights.

THE GENERALISATION GAP (suspected sharpest gap — Kitamura 2017 gives the concrete design). Biology does NOT wait for a nightly job to decide what to promote. The prefrontal (semantic) engram is written AT ENCODING TIME, born silent, and matures over ~2 weeks under hippocampal drive while the episodic copy goes silent. Ported: memory-nightly should not only fold events into state, it should emit a SILENT CLAIM/PROCEDURE STUB at the moment an episode lands, then mature that stub across successive folds (each recurrence adds a trial), and finally attenuate the episodic retrieval route. That converts ETTZ's fold from a batch recomputation into an incremental maturation — which also attacks the cold-fold 60s+ scaling pain, since maturation is O(new events) rather than O(71k).

CO-ALLOCATION WINDOW = the missing cheap generalisation mechanism. Cai 2016 / Rashid 2016 show temporal proximity is computed by a leaky excitability variable with a ~6-24 h time constant, producing automatic linking of events close in time and active DISALLOCATION of distant ones. ETTZ has BEATS (15s), timestamps and flow refs, but no rule that co-tags temporally adjacent envelopes into a shared ensemble. Adding a decaying eligibility score per subject/organ — and co-stamping an ensemble id when two events arrive inside the window — would give ETTZ automatic pattern formation without a clock-driven job. Note the second half: disallocation is ACTIVE, so distant events should be pushed into disjoint ensembles, not merely left unlinked.

HEBBIAN STRENGTHENING BEYOND USAGE BALANCES. The BANK's usage balances are already a proto-excitability variable, but biology uses excitability for ALLOCATION (who gets recruited next), not just for ranking. Concretely: a recently/heavily used prompt, tool or source should be preferentially recruited into the next item's ensemble — that is what produces linking and is where CHOICE envelopes could feed back into a real Hebbian loop rather than a leaderboard.

COMPRESS-AND-ARCHIVE-NEVER-ERASE (owner's absolute law — validated). Ryan & Frankland 2022 is the strongest external support: biological forgetting is a reversible accessible→inaccessible state transition, not deletion, and the ONLY demonstrated true erasure (Han 2009) requires destroying the allocated units themselves. ETTZ's 'close the window, never delete' on claims is precisely the biological default; QUARANTINE with .why.md manifests is the accessibility switch; the CUSTODIAN interlock ('does a verified snapshot hold this?' blocks the delete) is the correct guard, because Han 2009 shows unit destruction is the one irreversible operation. Note the asymmetry the owner should exploit: silencing must be CHEAP and reversible while destruction is EXPENSIVE and gated — ETTZ has the gate but no cheap silencing primitive for episodic material (only quarantine, which is heavyweight).

SILENT ENGRAM = a diagnostic ETTZ lacks. Biology can distinguish 'stored but unreachable by natural cue' from 'gone' by bypassing cues with direct activation. ETTZ should expose the same two-path read: a cue-driven retrieval (semantic/contextual match) and a direct id-addressed retrieval (content-hash, flow ref, ensemble id). If the direct path returns and the cue path does not, the item is silent-not-lost, and the repair is to restore associations, not to re-ingest. This is a measurable health metric for the IGNORANCE GRAPH and DESIDERATA.

SYNAPSE-SPECIFIC IDENTITY (Abdou 2018) warns about the shared-ensemble failure mode: as ETTZ starts co-tagging temporally adjacent items, distinct claims sharing a subject must remain separable. The address must be (subject × ref pathway), i.e. flow-ref-qualified, or linking will collapse identity.

NOT ANSWERED BY THIS TOPIC: the filopodia/active-exploration question and use-dependent pruning by microglia are outside the engram literature — engram work says who gets recruited from an existing population, not how new connections are prospected. SOMA = organ core/harness is consistent with the engram unit being an addressable participant, but engram work adds that the unit is never the memory: erasing one unit degrades nothing, which argues ETTZ should never let a single organ be the sole holder of a claim.
