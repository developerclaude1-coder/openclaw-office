# neuro-research — working material behind the NEURO-MAPPING deliverables

This directory holds the full, unedited outputs of the research process that produced
[`../NEURO-MAPPING.md`](../NEURO-MAPPING.md), [`../ADOPTABLE.md`](../ADOPTABLE.md) and
[`../DOCTRINE-CONFLICTS.md`](../DOCTRINE-CONFLICTS.md). The deliverables are the curated distillation; this is
the evidence and argument behind every verdict, kept so a later session (see
[`../HANDOFF-LOCAL.md`](../HANDOFF-LOCAL.md)) can check the reasoning rather than trust it.

Machine-generated by the 2026-09-01 cloud session; the ETTZ-side statements in these files are cited from the
owner's brief and were **not** verified on the wire — see the provenance note in NEURO-MAPPING.md.

## biology/ — the literature sweep (12 areas)

One file per mechanism area: a mechanistic summary written for a systems engineer, the discrete computational
mechanisms (signal / tag / threshold / timescale), every citation with the claim it supports and its PubMed
verification status, and the researcher's notes on which ETTZ design questions the area bears on.

- `00-CRITIQUE.md` — the verification critic's pass over the whole sweep: thin areas, misattributed or contested
  citations (binding — see NEURO-MAPPING.md § Citation integrity), and eleven cross-cutting mechanisms the sweep
  had missed. **Read this before relying on any single area file**, since the area files predate the corrections.
- `neurogenesis.md`, `growth-cones.md`, `synaptogenesis.md`, `hebbian-ltp-ltd.md`, `tagging-capture.md`,
  `microglia-pruning.md`, `astrocytes.md`, `neuron-anatomy.md`, `myelination.md`, `sleep-consolidation.md`,
  `engrams.md`, `forgetting-apoptosis.md`

## mapping/ — the adversarial analyses (14) and the judgment

One file per candidate mapping. Each analyst was required to argue both directions, state the strongest
objection to its own verdict, show the verdict survives it (or change it), enumerate missing pieces, and propose
the smallest doctrine-compliant adoption with cost, risks and owning session.

- `00-JUDGMENT.md` — the cross-mapping judge: five over-claims corrected, seven contradictions surfaced, the
  unified proposal ranking, and the ruling on the sharpest-gap hypothesis. **The judge's corrections override the
  analyst files where they differ** (e.g. filopodia is *missing*, not partial; A-002 counts as absent until
  enforced; the `.why.md` manifest is a receipt, not a tag).
- `filopodia-exploration.md`, `microglia-pruning.md`, `soma-organ-core.md`, `hebbian-strengthening.md`,
  `synaptic-tagging.md`, `sleep-replay.md`, `neurogenesis-joining.md`, `active-forgetting-abstraction.md`,
  `signal-substrate.md`, `astrocytes-support.md`, `engrams-distribution.md`, `apoptosis-vs-necrosis.md`,
  `doctrine-conflicts.md`, `reverse-gap-hunt.md`
