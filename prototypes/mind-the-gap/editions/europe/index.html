      About this data. Every institution, residency and commission listed here is real and was checked against primary sources. Even so: programmes change, funding changes, and application windows move every year. This is not an application portal — always confirm current terms with the organisation directly using the source link on each card. Listings added or re-checked in November 2026 were read from the organisers’ own pages as quoted by a search engine, without opening the pages themselves, so none of them is rated above medium.
